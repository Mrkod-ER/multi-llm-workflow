# Security Policy

## Supported Versions

Currently, only the main integration branch and latest release are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to **rohitgurjar.khari@gmail.com**. You should receive a response within 48 hours. If the issue is confirmed as a vulnerability, we will open a draft security advisory and provide a timeline for a patch.
